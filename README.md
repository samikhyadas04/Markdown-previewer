# Markdown-previewer
A sleek, dark-themed Markdown Previewer built with React.js. Type markdown on the left and instantly see the rendered preview on the right — live, side by side.

## ✨ Features

- 📝 **Live Preview** — renders markdown instantly as you type
- 🖤 **Dark Professional Theme** — sleek black UI with color-coded syntax
- 📊 **Word & Character Count** — live stats shown in the editor header
- 📋 **Copy to Clipboard** — copy your markdown with one click
- ⬇️ **Download as `.md`** — save your work as a markdown file
- 🗑️ **Clear Button** — reset the editor instantly
- ✅ **GitHub Flavored Markdown** — supports tables, strikethrough, line breaks, and code blocks

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| React.js | UI & state management |
| useState Hook | Managing markdown input state |
| marked.js | Markdown to HTML conversion |
| CSS | Custom dark theme styling |

## Installation
# Clone the repository
git clone https://github.com/your-username/markdown-previewer.git

# Move into the project folder
cd markdown-previewer

# Install dependencies
npm install

# Start the development server
npm start

The app will open at http://localhost:3000 in your browser.
